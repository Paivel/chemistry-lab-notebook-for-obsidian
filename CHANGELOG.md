# Changelog

Each version of the vault is a GitHub release with two archives: `Chemistry-Lab-Notebook-vX.Y.Z.zip`, the whole vault for a new start, and `Plugins-update-vX.Y.Z.zip`, the notebook's own plugins without their settings for updating an existing vault (see [docs/updating.md](docs/updating.md)).

## v1.0.0

First public release.

- Plugins written for this notebook: CDX Scheme Image 1.8.13, Reaction Structure Search 1.9.10, Chemistry Word Report 1.2.3, Reactio Draw 0.10.2 (with Reactio Draw 1.15.2), TLC Photo Inbox 1.3.1, NMR Downloader 1.8.7, Template Guard 1.4.1, Kanban Day Planner 0.1.1, Open Files Directly 0.1.0 (off until the user turns it on).
- Modified plugin: Chronology Custom 1.1.14-pavel.1.
- Third-party plugins and their versions: [THIRD_PARTY_LICENSES/SOURCES.md](THIRD_PARTY_LICENSES/SOURCES.md).
