# Third-party software licenses

This vault redistributes compiled copies of third-party Obsidian plugins for a reproducible and convenient installation.

The plugins remain the property of their respective authors. Their inclusion does not transfer ownership to the maintainer of this vault. See `SOURCES.md` for plugin versions, upstream repositories, and the applicable license text.

The complete standard license texts are stored in this directory:

- `MIT.txt`
- `Apache-2.0.txt`
- `GPL-3.0.txt`
- `AGPL-3.0.txt`

The upstream license file of each component, including its copyright notice, is stored in `licenses/<component>/`.

Modified plugins are identified explicitly. Their modification notes (`CHANGES.md`) are in the corresponding plugin directories and in `plugin-notices/`, together with a unified diff of the changes relative to the official release build.

For GPL-3.0 and AGPL-3.0 components, redistributors must also make the complete corresponding source code for the exact distributed build available under the terms of the applicable license. The upstream source archives for the exact versions are included in this directory.
