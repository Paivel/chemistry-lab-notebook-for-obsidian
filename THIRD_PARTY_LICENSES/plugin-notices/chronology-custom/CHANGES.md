## Modified build — 2026-04-07

- The compiled main.js file was modified for use in the author's Obsidian laboratory-notebook workflow.
- The plugin is distributed under the custom identity chronology-custom and the display name Chronology Custom.
- The original MIT License is preserved in the accompanying LICENSE file.

The starting point was the official release build of version 1.1.14 (https://github.com/Canna71/obsidian-chronology/releases/download/1.1.14/main.js).
The complete list of changes relative to that build is provided as a unified diff in `THIRD_PARTY_LICENSES/plugin-notices/chronology-custom/main.js.diff` (the `/* nosourcemap */` marker that Obsidian appends to installed plugins is ignored). The upstream source code of version 1.1.14 is provided in `THIRD_PARTY_LICENSES/obsidian-chronology-1.1.14.zip`.

- `styles.css` was changed too (the calendar's look: the week-number column hidden, today in bold, days of other months faint, own chevrons, the month and year centred in the header). The changes relative to the release's `styles.css` are in `THIRD_PARTY_LICENSES/plugin-notices/chronology-custom/styles.css.diff`.
